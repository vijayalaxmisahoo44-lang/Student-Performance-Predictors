Student-performance-predictors

The **Student Performance Predictor & Analyzer** is a Python-based Machine Learning project that analyzes student academic data and predicts their final performance.

The project uses **Python, Pandas, NumPy, Matplotlib, and Scikit-learn** for data analysis, visualization, regression, and classification.

An interactive **Streamlit** application will also be developed to allow users to enter student details and get a predicted score and performance level.

---

##  Objectives

- Analyze student academic data.
- Understand factors affecting student performance.
- Perform data analysis using Pandas and NumPy.
- Create different data visualizations.
- Predict the student's final score.
- Classify students into different performance levels.
- Compare different Machine Learning models.
- Build an interactive application using Streamlit.

##  Dataset

The dataset will contain student-related information such as:

| Feature | Description |
|---|---|
| `study_hours` | Number of hours spent studying |
| `attendance_percent` | Student attendance percentage |
| `assignments_completed` | Number of completed assignments |
| `previous_score` | Previous academic score |
| `sleep_hours` | Average sleeping hours |
| `screen_time_hours` | Daily screen time |
| `final_score` | Final academic score |
| `performance_level` | Student performance category |

### Performance Levels

- **Excellent** → 75 or above
- **Good** → 60–74
- **Average** → 45–59
- **Needs Improvement** → Below 45

> **Note:** The initial dataset will be used for educational and project purposes.
